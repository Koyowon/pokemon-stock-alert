# PC 온라인 포켓몬 상품 재입고 감시 (설계 및 검증 대기)

## 목적
기존 편의점 모니터를 변경하지 않고 Windows PC에서 별도 프로세스로 실행하는 온라인몰 감시기를 개발한다.
감시 상품: (1) Pokémon GO Plus + (국내 기준가격 64,800원), (2) 포켓몬카드 30주년 상품(정확한 상품 SKU별 정가를 확인한 후 등록).
기존 Telegram 봇의 환경변수 기반 설정을 재사용하되 토큰을 저장소에 기록하지 않는다.

## 우선 조사 대상
- 포켓몬스토어 공식몰
- 게임터치몰
- 기존 사용자 등록 온라인 정가 판매처: 네이버 공식 스마트스토어, 카드매니아, G마켓, 11번가, SSG, 롯데온
- 판매자 신뢰도와 공식 정가를 확인할 수 없는 상품은 알림 대상에서 제외

## 실행 정책
- 사이트별 공개 페이지 또는 허용된 API를 통한 재고 확인만 사용한다.
- 차단, CAPTCHA, 로그인·결제 제한을 우회하지 않는다.
- 요청 주기는 판매처별 허용 범위, 응답 코드, Retry-After, 장애율에 따라 결정하며 5~10초를 보장하지 않는다.
- UNKNOWN/ERROR 상태를 품절로 취급하지 않는다. 실제 구매 가능 확인 후에만 입고 알림을 전송한다.
- Telegram 메시지에는 상품명, 확인 시각, 가격, 판매처, 직접 구매 URL을 포함한다.
- 상품/판매처별 상태 전이 및 재알림 쿨다운으로 중복 알림을 방지한다.
- 주문·결제·장바구니 자동화는 범위에서 제외한다.
- Windows 작업 스케줄러 자동 시작, 프로세스 복구, 로그 회전, 오프라인 모의 테스트를 지원하도록 구현한다.
- main 및 기존 운영 워크플로, 편의점 상태 파일을 수정하지 않는다.

## 현재 상태
설계 범위 확정. 판매처별 접근 정책, 실제 상품 URL, SKU, 정가 및 재고 판별 방식 검증 전.
**실제 감시기 구현·PC 설치·실시간 감시 시작 전.**
