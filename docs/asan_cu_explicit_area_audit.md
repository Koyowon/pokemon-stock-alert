# 아산 CU 지역 분류 정밀 오프라인 검토

날짜: 2026-10-13. 브랜치: permission-test-20261013-cu.
기초자료: asan_cu_watch_registry.json 및 docs/asan_cu_address_normalization_review.csv.
산출물: docs/asan_cu_explicit_area_review.csv (119행), docs/asan_cu_area_search_priorities.csv (지역별 요약).

## 검증 결과

- 등록 후보 119개 유지. 기존 area가 비어 있거나 '주소 미확인'인 23개 중 **19개**는 주소의 명시적 읍·면·동 표기에서 분류 가능.
- 기존 첫 토큰 추출 실패 31개 중 **27개**는 괄호 안 행정구역 등 주소의 명시적 표기에서 확인 가능.
- 전체 분류 보류 7개: ASAN-CU-022, ASAN-CU-027, ASAN-CU-060 (기존 area='삼동', 주소 괄호의 권곡동/모종동과 충돌); ASAN-CU-099, ASAN-CU-110, ASAN-CU-111, ASAN-CU-113 (읍·면·동을 주소에서 직접 확인 불가).
- 보류 7개 중 3개는 '충돌', 4개는 '직접 증거 없음'. 도로명·점포명만으로 임의 지역 추정 금지.
- 모든 지역 분류는 주소 문자열에서 추출한 근거이며 공식 행정구역 검증 결과가 아님. 법정동/행정동 차이도 별도 확인 필요.

## 지역별 확인 우선순위

기존 검색 좌표는 (36.790,127.000), (36.775,127.050), (36.795,127.065), (36.805,127.095), (36.798,127.115), (36.830,127.070), (36.920,127.065) 총 7개. **CU API 검색 반경·결과 제한·반환 누락 여부는 검증되지 않음.** 따라서 아래 우선순위는 지역별 미확보 코드와 후보 수를 기준으로 한 *데이터 정비 우선순위*이며 지리적 사각지대 확정 순위가 아님.

- P0: 지역 미확정 7개(그중 코드 미확보 6개) — 주소·분류 충돌 확인.
- P1: 배방읍 27개(코드 미확보 19), 둔포면 16개(12), 음봉면 10개(10) — 대규모 코드 미확보 집단.
- P2: 모종동 7개(7), 신창면 7개(7), 탕정면 14개(6), 인주면 5개(5), 영인면 4개(4) — 중간 규모 미확보 집단.
- P3: 기타 소규모 지역. 구체 수치는 CSV 참고.

## 검색 좌표와 비교하는 방법

현재 후보 좌표는 3개뿐이므로 나머지 116개 후보에 대해 검색점과의 실제 거리 계산 불가. 검색점 좌표만으로 특정 읍·면·동을 '커버한다'고 판정하지 않음. 다음 단계는 공식 근거가 있는 주소·좌표 보완 후 **오프라인 최근접 검색점 거리**를 계산하는 것. 이 거리 역시 API 조회 성공을 보장하지 않음.
