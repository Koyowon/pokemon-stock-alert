## 결과

공개 제3자 API `https://mcp.aka.page`의 전주시 재고 요청이 HTTP 200으로 회복됐다. 공식 세븐일레븐 직접 조회를 검증한 결과는 아니다. 기존 502의 근본 원인은 확정하지 못했다.

- 점포 검색 결과: 전주시 135곳 (완산구 69, 덕진구 66).
- `storeKeyword=전주시&storeLimit=200` 재고 응답: 100곳. 응답 `totalStoreCount`도 100이므로 이 수치만으로 지역 전체 조회 완료를 판정하면 안 된다.
- 상품 바코드 8800286275732, 상품명, 응답 100곳의 점포코드·매장명·주소를 기존 점포 목록과 대조해 모두 일치했다. 전북 도명 별칭 및 공백만 정규화했다.
- 100곳 중 API 수량 0은 6곳, 수량 -1(미확인)은 94곳. 나머지 35곳은 응답 누락으로 미확인이다. 전체 목록 기준 6곳 수량 0 / 129곳 미확인 / 양수 수량 0곳이다. 실물 품절 여부는 검증하지 않았다.
- 전주팔복프라임점 단일 요청: HTTP 200, 수량 0. 전주효자더샵점: HTTP 200이지만 stockAvailable=false, 수량 -1이므로 미확인.
- 남원남문로점 대조 요청: HTTP 200, 수량 0.
- 완산구·덕진구 문자열로 나눈 점포/재고 요청 4건은 모두 HTTP 502. 누락 점포 중 전주송천우림점·전주중화산어은점·전주도청CGV점 단일 요청 3건도 HTTP 502. 오류 코드는 CONVENIENCE_RELAY_FAILED이고 upstreamStatus=502다.
- 이번 실제 호출은 총 11회 (HTTP 200 4회, HTTP 502 7회), 자동 재시도·리디렉션·인증 우회 없음. 픽업 가능 여부만으로 성공을 예측할 수 없다 (픽업 가능인 누락 점포 3곳도 실패).
