# 재고 현황판 지도와 주소 복사

## 기능

기존 건강 상태 현황판에 Leaflet 지도를 추가했다. 기본 표시 대상은 기존 화면에서 현재 수량이 정상으로 확인된 양수 재고 매장이다. 지역·브랜드·상태·원인·검색 필터를 그대로 따른다. ‘0개 매장도 지도에 표시’를 켜면 확인된 숫자 0도 회색 핀으로 표시한다. 미확인 또는 만료 수량을 재고 있음으로 표시하지 않는다.

핀 팝업은 브랜드/매장명, 현재 수량, 마지막 수량 확인 시각(KST), 주소, 주소 복사 버튼과 위치 확인 출처를 제공한다. 동일 좌표에 매장이 여럿 있으면 한 핀에 수량을 합산하고 팝업에 매장별로 표시한다. 좌표 없는 매장도 표의 주소 복사 버튼을 이용할 수 있다. GS25 등 원본 주소 기록이 없고 확인된 좌표 등록도 없으면 ‘주소 확인 필요’로 보류한다.

주소 복사는 버튼을 눌렀을 때만 수행한다. 클립보드 접근이 제한되면 선택 가능한 읽기 전용 주소란을 제공한다. 매장명·주소 등은 팝업에서 textContent로 표시한다. 지도 라이브러리를 읽지 못해도 기존 표와 주소 복사는 동작한다.

## 좌표의 현재 한계

main의 CU·이마트24·GS25 자료에는 독립 검증된 점포 좌표가 없다. 보류 중인 PR #5도 빈 좌표 등록부를 사용한다. 세븐일레븐 자료의 위도·경도는 제3자 API 제공값이며 독립 대조가 완료되지 않았다. 이를 검증된 위치로 승격하지 않았다.

`docs/stock/verified_coordinates.json`의 운영 등록은 현재 **0건**이다. 따라서 이번 배포만으로 실제 점포 핀이 새로 나타나지는 않는다. 지도 기능과 팝업을 테스트한 것은 합성 테스트 자료이며 운영 위치/재고로 등록하지 않았다. 실제 핀을 채우려면 별도로 출처에서 매장명·주소·좌표의 동일 매장 여부를 확인해야 한다.

등록에는 chain, 문자열 code, name, address, 숫자 latitude/longitude, verified=true, HTTPS source_url, verified_at이 필요하다. 브랜드+코드 중복, 다른 이름/알려진 주소 불일치, 잘못된 좌표, 미검증 표기, 미래 검증 시각, 잘못된 출처 URL은 핀에서 제외한다. 원본 주소가 없는 경우에만 코드/브랜드/이름이 일치하는 검증 등록 주소로 보완한다. 실제 출처 대조는 검토 단계에서 이루어지며 메타데이터 검사만으로 좌표의 실재를 입증하지 않는다.

지도 초기 중심 [36.3,127.3]은 단순한 화면 시점이며 매장 좌표가 아니다. 조회 중심·주소 추정·임의 지오코딩으로 점포 핀을 만들지 않는다. 기존 재고·모니터·알림·워크플로는 변경하지 않는다. 새 재고 API 또는 위치 권한 요청도 없다.

## 지도 출처와 요청

Leaflet 1.9.4는 공식 안내의 고정 버전 및 무결성 해시로 불러온다.
https://leafletjs.com/examples/quick-start/

배경 타일은 `https://tile.openstreetmap.org/{z}/{x}/{y}.png`이며 OpenStreetMap 저작자 표기를 표시한다. 브라우저 기본 캐시와 Referer를 사용하고 대량 다운로드/오프라인 선행 수집은 하지 않는다. 타일에는 재고 JSON의 no-store 옵션을 적용하지 않는다.
https://operations.osmfoundation.org/policies/tiles/
