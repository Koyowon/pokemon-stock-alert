## 공통 판정 원칙

- 두 기록에서 CU 코드가 같다는 사실은 **코드 문자열 연결**을 뒷받침할 뿐, 실제 위치 동일성·점포 이전·개명을 확정하지 않는다.
- 현재 세 건 모두 `HOLD_UNVERIFIED`. 원본 주소·점포명은 그대로 보존하며 자동 주소 통합, 레지스트리 갱신, 모니터링 승인, 재고 0 추론 금지.
- 필요한 근거는 **향후 별도 승인된 검토에서 요구할 항목**이며 이번 작업에서 조회하거나 확보하지 않았다.
- 판정 해제 게이트: (1) 검증 가능한 출처·기준일·점포 코드·주소 연결 근거, (2) 모순 없는 건물·상가·층·호수 식별, (3) 독립적인 검토 및 명시적 승인. 하나라도 없거나 충돌하면 보류 유지.
- 실제 점포 이전·개명 여부는 별도 공식 기록 없이는 `UNVERIFIED` 유지. 이름 유사성, 도로명 일부 일치, 건물번호 일치만으로 승인 금지.
