# CU·이마트24 공식 문의 초안 — 미발송

> 목적: 공개적으로 제공되는 점포 식별자의 존재 및 공식 확인 방법을 문의. 내부 API 접근 권한이나 비공개 정보 제공을 요구하지 않음. 실제 문의는 사용자가 공식 창구에서 제출해야 함.

## CU 고객상담실

**제목: 아산 지역 CU 점포 식별자 공식 확인 방법 문의**

안녕하세요. CU 매장 정보를 정확히 확인하고자 문의드립니다.

아산 지역 CU 매장들의 점포명과 도로명주소를 기준으로, 공개적으로 확인 가능한 공식 점포 식별자(점포코드)가 있는지 궁금합니다.

1. CU 공식 매장 검색 또는 포켓CU에서 일반 이용자가 점포명·주소와 함께 확인할 수 있는 공식 점포 식별자가 있나요?
2. 해당 식별자가 공개된다면 공식 확인 경로 또는 문서를 안내받을 수 있을까요?
3. 일반 이용자에게 공개되지 않는 정보라면, 매장명·주소의 동일성 및 점포별 재고 확인을 위한 공식적이고 허용된 방법을 안내해 주실 수 있을까요?

비공개 내부 시스템 접근 방법이나 비공개 데이터 제공은 요청하지 않습니다. 감사합니다.

공식 접수: https://cs.bgfretail.com/ (상담 유형 확인 후 제출). 전화: 1577-8007, 평일 09~18시.

## 이마트24 고객센터

**제목: 제주특별자치도 제주시 이마트24 점포 식별자 공식 확인 방법 문의**

안녕하세요. 제주특별자치도 제주시 소재 이마트24 매장 정보를 정확하게 구분하기 위해 문의드립니다.

1. 홈페이지/앱 매장 찾기에 표시되는 점포명·주소와 연결되는 **공개용 점포 식별자**가 있나요?
2. 공개된 식별자가 있다면 공식 매장 목록, 페이지 또는 안내 문서를 알려주실 수 있을까요?
3. 매장 찾기의 전화번호·지도 식별자와 점포코드가 다른 경우, 혼동하지 않고 점포를 구분할 수 있는 공식 방법이 있을까요?
4. 특정 상품의 점포별 재고를 확인하는 공식적이고 허용된 고객 이용 경로가 있나요?

비공개 재고 API, 내부 운영 시스템 또는 접근 권한을 요청하는 문의는 아닙니다. 감사합니다.

공식 접수: https://m.emart24.co.kr/helpdesk (온라인 문의). 전화: 02-6916-1500, 09~18시.

## 답변 기록 시 유의
- 공식 답변 원문과 접수일·답변일·담당 부서·공식 URL을 보관하되 개인정보·접수번호는 공개 GitHub에 업로드하지 말 것.
- 공개 여부가 확인되지 않은 코드, 매장 전화번호, 지도 ID, URL 순번은 `store_code`로 입력하지 말 것.
- 공개 자료에 점포명·주소·실제 코드의 연결이 증명되기 전까지 수동 검토 차단 유지.
