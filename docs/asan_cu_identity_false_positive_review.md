# 아산 CU 점포 식별 격리 정책 — 기존 기록 오탐 가능성 검토

검토일: 2026-10-13. 브랜치: `permission-test-20261013-cu`.
**자료 범위:** `cu_stock_state.json` 및 `asan_cu_watch_registry.json`만 사용. 외부 API·지오코딩·검색·실제 조회 없음.
점포별 결과: `docs/asan_cu_identity_false_positive_priorities.csv`.

## 비교 방법

- 레지스트리 119개 중 `cu_store_code`가 기존 상태 기록의 코드와 **정확히 일치하는 28개만** 대조. 나머지 91개는 동일 점포 추정·코드 부여 금지.
- 점포명·주소의 1차 비교는 유니코드 NFKC, 연속 공백 축약, 양끝 공백 제거.
- 이름만 추가로 `CU` 또는 `씨유` 접두어 제거 비교. 이 비교는 **표기 차이 진단**일 뿐 자동 식별 승인이나 운영 정규화 규칙 변경이 아님.
- 주소의 읍면동, 도로명, 번지, 건물명, 호수, 괄호 내용을 추론·수정·생략하지 않음.
- 기존 상태 기록은 과거 관측값이며 현재 점포 영업·재고·위치·점포명 변경 여부를 증명하지 않음.

## 주소 검토 사례 (코드 연결만 확인됨)

- `ASAN-CU-011` (28704): 레지스트리는 `아산로 116-21 (온천동)`; 상태 기록에는 `온천동 1928` 추가.
- `ASAN-CU-015` (30306): 상태 기록에는 쉼표와 `1층` 표기 추가.
- `ASAN-CU-040` (55802): 레지스트리는 `충청남도 아산시 배방읍 배방로 53`; 상태는 `충남 아산시 배방로 53`. 도로명 같아 보여도 독립 확인 전 주소 동등성 **미확정**.
- `ASAN-CU-083` (41691): 레지스트리는 `배방읍 공수리 282`; 상태는 `배방읍 모산로126번길 17-7`. 지번·도로명 관계를 추정하지 않음.
- `ASAN-CU-092` (27756): 상세 호수와 아파트 명칭이 서로 다르게 기재됨. 주소 동일성 **미확정**.
- `ASAN-CU-093` (27959): 두 기록이 똑같이 `아산시 배방읍` 반복·`102호호` 오류 의심 주소를 담고 있음. **문자열 일치는 주소 정확성의 증거가 아님**.

## 실제 식별 충돌 의심과 오탐 가능성의 구분

- **관측된 것:** 같은 기존 CU 코드로 연결된 두 저장 자료 사이의 점포명 접두어 및 주소 표기 차이.
- **미확정:** 실제 점포명 변경, 점포 이전, 주소의 동일 장소 여부, 같은 조회 주기의 API 응답 충돌.
- **실제 이름·주소 충돌 확정: 0건.** 단, 확인 가능한 28쌍에 한정되며 주소 불일치 19건은 수동 검토 대상임.
- 기존 두 파일은 시점과 수집 경로가 다를 수 있어 엄격 정책의 실제 운영 **오탐률을 계산할 수 없음**.

## 보수적 적용 권고

1. 운영 코드 수정 전, 같은 API 조회 주기에서 동일 코드의 이름·주소가 실제로 변하는지 승인된 별도 검증으로 확인할 것.
2. 원본 문자열을 보존하고, 비교 전 정규화 결과와 충돌 이유를 별도로 감사 기록할 것.
3. 접두어 차이는 오탐 후보로 표기하되 공식 식별 확인 전 자동 병합·개명 확정 금지.
4. 주소 문자열이 다른 19건은 동일 주소로 단정하지 말고 공식 주소 근거 확보 전 수동 검토 상태 유지.
5. 점포 코드가 없는 91개는 미연결 상태 유지. 이름·주소 유사성만으로 코드 부여 금지.
6. 미관측·미조회는 재고 0으로 전환하지 않음. 실제 API 검증·운영 반영은 별도 승인 필요.
