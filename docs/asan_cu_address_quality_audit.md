# 아산 CU 119개 주소 정규화·신뢰도 오프라인 점검

검토일: 2026-10-13
검토 원본: `asan_cu_watch_registry.json`
검토 산출물: `docs/asan_cu_address_normalization_review.csv`

## 방법과 한계

- 원본 119개 주소를 **수정하지 않고**, Unicode NFKC 및 연속 공백 축약으로 별도 `normalized_for_review` 문자열 생성.
- 비교용 주소 키에서 공백·괄호·일부 문장부호를 제외해 **완전 일치 후보**만 식별.
- `area` 필드와 주소에서 기계적으로 추출 가능한 첫 읍·면·동 토큰을 비교. **주소 안의 행정동과 법정동 차이, 괄호 표기, 도로명 주소 특성 때문에 불일치가 곧 오류는 아님.**
- 좌표는 원본의 위도·경도만 사용. 지오코딩·외부 조회·CU API 호출 없음.
- 검색 좌표 7개는 `cu_stock_monitor.py`에 존재하지만 CU API 검색 반경·반환 상한·페이지네이션·실제 점포 포함 여부가 확인되지 않아 119개 조회 보장을 주장하지 않음.

### 주소 중복 의심 (확정 중복 아님)

- `ASAN-CU-008` 씨유 아산관대점 ↔ `ASAN-CU-089` CU 아산퍼스트점: `충청남도 아산시 둔포면 충무로 1396`
- `ASAN-CU-078` 씨유아산테크노밸리2호점 ↔ `ASAN-CU-079` 씨유 아산제2테크노밸리점: `충청남도 아산시 둔포면 운용길 73`

동일 주소는 동일 점포·개명·폐점·복수 점포 중 어느 것도 단독 입증하지 못함. 병합·삭제·코드 부여 금지.

### 표기 의심

- `ASAN-CU-093`: `아산시 배방읍` 반복 및 `102호호` 표기. 과거 CU 저장 상태에서 그대로 가져온 주소. **원본 유지**, 외부 근거 확보 전 임의 교정 금지.
- `ASAN-CU-096`: `선문대학교` 반복. 건물·캠퍼스 설명이 중복된 것일 수도 있어 검토 필요.

## 검색 범위 확대를 위한 안전한 순서

1. P0 2개 충돌 쌍과 ASAN-CU-093 주소의 원본 출처 확인. 동일 점포로 임의 병합하지 않음.
2. `area` 미해결 23개와 주소 첫 토큰 추출 불가 31개를 **별도 검토 표에서만** 수동 분류. 원본은 그대로 보존.
3. CU 코드 미확보 91개에 대해 CU 전용 출처가 확인되는 경우에만 코드 연결.
4. 주소 정확도 검증 후 별도 승인된 지오코딩 방법으로 좌표를 확보. 현재 116개 좌표 미확보.
5. 좌표가 확보되면 기존 7개 검색점과의 최근접 거리·지역별 분포를 오프라인으로 산출하고, 송악면·신창면·인주면·영인면·둔포면·음봉면 및 배방읍·탕정면 외곽의 사각지대 가능성을 우선 평가. **거리만으로 API 포함 여부를 단정하지 않음.**
6. API 검색 반경·반환 상한 등은 별도 실조회 승인 전까지 미확인으로 표시. 검색 좌표 증설은 이 검증 이후 검토.
