## 오류 원인 범위

단일점 진단에서 HTTP 502 응답 본문의 error.code와 diagnostics.code가 CONVENIENCE_RELAY_FAILED, operation이 seveneleven_request, upstreamStatus가 502로 확인됐다. 공급자 응답은 외부 서비스 오류라고 설명한다. 현재 환경에서 관찰한 릴레이 실패까지 확인했으며 외부 서버의 근본 원인을 해결했다고 주장하지 않는다.

전주가 단순히 조회 점포 수가 많아서 실패한다고 단정하지 않기 위해 전주시 덕진구 및 전주영생점 범위도 확인했지만 같은 502였다. 다른 숨은 경로·인증 우회·임의 좌표로 대체하지 않았다. 숫자 응답이 없는 전주 전체를 재고 없음으로 만들거나 기존 편의점 운영을 변경하지 않았다.
