## 계산 방식과 결과

- 점포의 위도·경도가 모두 유효할 때만 7개 검색 좌표에 대한 Haversine 대원거리 계산.
- 지구 평균 반경 `6371.0088 km` 적용. 단위 km, 소수 셋째 자리 반올림.
- 3개만 `CALCULATED`, 나머지 116개는 `NOT_CALCULATED_NO_COORDINATES` 및 **거리 공란**. 거리 미산출을 0km 또는 조회 불가로 해석하지 않음.
- `ASAN-CU-066` 씨유 아산신정호공원점 → 1번 검색점, **2.583 km**.
- `ASAN-CU-090` CU 온양제일호텔점 → 1번 검색점, **0.879 km**.
- `ASAN-CU-092` CU 아산팬더점 → 1번 검색점, **0.546 km**.
- 세 점포가 모두 1번에 가장 가까운 것은 다른 여섯 검색점이 불필요하다는 증거가 아님.

## 미확인 API 계약 및 검증 보류

**CU API 검색 반경, 최대 반환 건수, size=100의 의미, offset/page 처리, 결과 정렬, 좌표 기반 필터링, 품절 점포 포함 여부, 오류/부분 성공 동작은 모두 미검증**. 또한 API의 특정 좌표 검색 결과에 119개 점포가 모두 포함된다는 증거 없음.

| 검증 조건 | 현재 상태 | 증거 요건 |
|---|---|---|
| 후보 119개 고유 식별 | 등록 ID 119개 | 코드/주소/명칭 대조 |
| CU 코드 확보 | 28개 보유, 91개 미확보 | CU 전용 출처의 점포 코드 |
| 위치 좌표 확보 | 3개 보유, 116개 미확보 | 출처·정밀도가 기록된 좌표 |
| 검색 반경 | 미확인 | 명시적 API 문서 또는 승인된 제한적 조회 결과 |
| 반환 상한 및 페이지네이션 | 미확인 | 문서 또는 승인된 경계값 검증 |
| 119개 실제 조회 가능 | **입증 안 됨** | 점포별 관측 여부·요청 성공 여부·중복 제거 검증 |
| 재고 0 확정 | **입증 안 됨** | 명시적 유효 재고값 0 응답 |
| 알림 안전성 | 운영 변경 없음 | 승인 후 격리된 테스트, 운영 알림과 분리 |

## 감시 범위 확대를 위한 안전한 실행 순서

1. **현재 단계(완료):** 저장소 자료만으로 119개 등록 후보·7개 검색점의 오프라인 거리표 생성. 원본과 운영 코드 유지.
2. **데이터 정비:** 원본 보존, 지역 미확정 7개와 중복 의심 4개 확인, CU 코드 미확보 91개는 검증된 근거로만 연결.
3. **좌표 검증:** 별도 승인된 신뢰할 수 있는 지오코딩/지도 출처로 116개 점포 좌표 확보; 정확도와 출처를 기록. 검증 전 좌표 임의 생성 금지.
4. **거리 재산출:** 점포별 최근접 검색점·지역별 분포·좌표 미확보율 산출. 거리는 커버리지 **계획 지표**이지 API 포함 증거가 아님.
5. **별도 명시적 승인 요청:** 실제 CU API 테스트의 요청 횟수, 시각, 대상 지역, 타임아웃, 결과 보관, 속도 제한 및 중단 기준 합의. 승인 전 실행 금지.
6. **승인 후 별도 격리 환경:** 알림/운영 상태 저장을 끄고 제한된 조회로 반경·반환 상한·페이지네이션·오류 동작·중복 여부 검증. 성공 응답의 미관측 점포는 `NOT_OBSERVED`, 조회하지 않은 점포는 `NOT_QUERIED`로 유지.
7. **확대 판단 게이트:** 명시적으로 검증된 점포 식별자, 좌표, 조회 범위 및 중복 제거를 만족할 때만 검색점 추가 검토. 새 좌표의 필요성·중복·비용/요청 제한을 비교하고 승인 전 운영 반영 금지.
8. **운영 이행:** 사용자 별도 승인 후에만 작업 브랜치 변경 검토·테스트·운영 반영. 남원/전주/제주 및 Telegram 로직 보호.
